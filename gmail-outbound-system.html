⚙️ 최초 설정 필요
Google Cloud Console에서 OAuth 2.0 클라이언트 ID를 발급하고 아래 설정 버튼에 입력하세요. Gmail API와 Sheets API를 활성화해야 합니다.
Google OAuth 설정
Google Cloud Console → API 및 서비스 → 사용자 인증 정보에서 발급한 클라이언트 ID를 입력하세요.
설정 방법:
1. console.cloud.google.com 접속
2. 새 프로젝트 생성 → Gmail API, Sheets API 활성화
3. OAuth 동의 화면 설정 (외부, 테스터에 내 이메일 추가)
4. 사용자 인증 정보 → OAuth 클라이언트 ID 생성 (웹 앱)
5. 승인된 JavaScript 원본에 이 파일의 URL 추가
